# Mobil tasarım yenilemesi — 18 Ekim 2026

Mobil arayüz, web'deki Keşfet ve Atölye Akışı'nın görsel diline taşındı. Bu değişiklikte web veya backend kaynakları düzenlenmedi. Ekranlar React Native; mevcut site açılmıyor.

## Tasarım kararları

| Öğe | Mobil karşılığı |
| --- | --- |
| Web'in kâğıt zemini | `#F7F5F0`, kartlarda `#FFFDF8` |
| Kiremit vurgusu | `#863E27`; ana eylemler, seçimler, ince üst çizgi |
| Mürekkep ve ince çizgiler | `#281F18`, `#DDD2C2` |
| Başlık | Yerel Playfair Display SemiBold |
| Arayüz | Yerel DM Sans Regular / Medium / SemiBold |
| Okuma ve günlük metni | Yerel Lora / Lora Italic |
| Kartlar | Küçük köşe yarıçapı, ince kenar, seçili tanıtım alanında tek kıvrımlı köşe |
| Kapaklar | Gerçek kapak; görsel yoksa gerçek eser başlığıyla kitap cildi görünümü |
| Uygulama ikonu | `frontend/public/acb.svg` işaretinden türetilmiş kiremit ACB; web kaynağı değiştirilmez |

Fontlar `assets/fonts/` içinde OFL lisanslarıyla paketlenir. Başlangıçta internetten font indirilmez. Yerel WebView editörü güvenli HTML belgesinde platform serif yazısını kullanır; bu belgenin paleti, boşlukları ve biçimlendirme çubuğu da yenilendi.

## Yenilenen alanlar

- Beş sekmeli gezinme: ACB başlığı, bildirim kısayolu, çizgisel ikonlar, ince alt menü. Alt menü yüksekliği sistem yazı ölçeğine göre büyür; etiketler iki satıra çıkabilir.
- Akış: tarih başlığı, yazı masasına dönüş, çizgiyle seçilen kapsam sekmeleri, açılır günlük paylaşımı, yazar avatarı ve Lora metinli günlük kartı, küçük kitap bağlantısı, sade sosyal eylemler.
- Keşfet: web'deki kiremit üst çizgili tanıtım alanı, ikonlu arama, hikâye/yazar sekmeleri, yatay tür filtreleri, seçili sıralama ve kitap rafı listesi.
- Kütüphane: gerçek ilerlemeye bağlı devam kartı, okuma yüzdesi, kitap listesi, okuma listesi/alinti defteri satırları.
- Atölyem: belirgin yeni eser eylemi, sade eser rafı ve not defteri. Cihaz kopyaları ve eşitleme hata durumları korunur.
- Profil ve yazar sayfası: avatar, serif isim, gerçek istatistikler ve bölünmüş menü. Uzun kullanıcı adları büyütülmüş metinde ekran içinde satıra geçer.
- Karşılama/kayıt/giriş/profil tamamlama: web paleti, belirgin başlık, aynı alan ve düğme sistemi. Yeni Google hesabında kullanıcı adı seçimi korunur.
- Eser detayı: kapak alanı, yazar/tür, okuma ve rafa ekleme, hikâye özeti, numaralı bölüm listesi.
- Eser atölyesi: kapak/başlık, tek ana bölüm oluşturma eylemi, hikâye araçları ve bölüm satırları.
- Yazı alanı: sıkışmayan kayıt/kelime durumu, yardımcı panel kısayolu ve 44 px dokunma alanlı biçimlendirme ikonları. Editör komutları ve taslak motoru korunur.
- Okuma: Lora/DM Sans tercihi, sade Aa paneli, bölüm numarası ve gece modu kontrolleri.
- Hikâye araçları: seçili durumları belirgin yatay araç sekmeleri ve perde/tür filtreleri. Bildirimler: yeni/okunmuş ayrımı ve dokunulabilir satırlar.
- Diğer ekranlar ortak alan, hata, boş içerik, kart ve düğme sistemini kullanır.

## Doğrulama

TypeScript, lint ve mevcut **55/55 mobil test** geçti. `expo install --check` SDK sürümlerini uyumlu buldu. Android ve iOS Hermes export üretildi. Backend değişmediğinden önceki 815 test sonucu bu tasarım için yeniden çalıştırılmış gibi sunulmaz.

Gerçek ekran bileşenleri, ayrı geliştirici aracında React Native Web üzerinden Edge'de render edildi. Ağ/oturum/veri adaptörleri kontrollü test verisi kullanır; bu veriler native uygulamaya dahil edilmez. **15 ekran × 2 genişlik = 30 görünüm**, 320 ve 390 px genişlikte kontrol edildi. Yatay sayfa taşması ve görünür eylemlerin ekran dışına çıkması kontrolü geçti. Görseller `artifacts/design/` altında üretilir; bu dizin Git'e alınmaz.

Ek geçen kontroller:

- Arama → sonucu daralt → temizle → tür seç.
- Yazı araçlarını aç → gerçek yerel editör belgesinde metin ekle → kontrollü kayıt adaptörüyle kaydet → metnin kaldığını doğrula.
- Okuma tercihlerini aç → gece moduna geç.
- Uzun kullanıcı adında tarayıcı metnini 1,6 kat büyüt → başlığın ekran sınırları içinde kaldığını doğrula.

Tarayıcı metin büyütmesi native sistem yazı ölçeği kabul testi değildir. Fiziksel Android/iOS klavyesi, IME, VoiceOver/TalkBack, güvenli alanlar ve uygulama yaşam döngüsü bu ortamda doğrulanmadı. Android emulator aracı mevcut olsa da yapılandırılmış AVD ve bağlı telefon yok; Windows'ta iOS simülatörü yok.

## Tekrar çalıştırma

Mobil bağımlılıklarını ve repo frontend geliştirme bağımlılıklarını kurduktan sonra:

```powershell
cd Z:\acbAstra\mobile
npm.cmd run typecheck
npm.cmd run lint
$env:MOBILE_EDITOR_BROWSER = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm.cmd test
node scripts/design-preview.mjs
```

Başka terminalde aynı dizinde `node scripts/check-design-browser.cjs`. Görsel kontrol sunucusu yalnızca `127.0.0.1:5186` üzerinde, kontrollü örnek verilerle çalışır. Üretim uygulaması için sunucu değildir. İkonu web vektöründen tekrar üretmek için `node scripts/build-brand-assets.cjs`.

Native paket: `npm.cmd run android:preview`. Sürüm **1.0.1 / Android versionCode 2**; mevcut aynı imzalı deneme paketinin üzerine güncelleme amaçlıdır. Mevcut yerel HTTP API ve geliştirme imzası sınırı devam eder. Güncel APK özeti ve son native derleme sonucu [VALIDATION.md](VALIDATION.md) içinde tutulur.
