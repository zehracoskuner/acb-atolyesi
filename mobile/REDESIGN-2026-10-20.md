# Mobil yeniden tasarım — 20 Ekim 2026

Bu değişiklik mevcut Expo Router / React Native uygulamasındadır. Web ekranları ve ortak backend özellikleri kaldırılmadı. Üretim ekranlarında örnek veri yoktur; `scripts/design-preview` yalnızca açıkça ayrılmış görsel test verilerini kullanır.

## Web–mobil eşleşmesi

| Aktif web kaynağı | Mobil karşılık / veri sözleşmesi |
| --- | --- |
| `ProfilePage.jsx`, `ProfilePage.css`, `LogTab.jsx` | Ortak `ProfileScreen`: banner/avatar, kimlik, takip listeleri, günlük, eserler, sahibinin taslakları ve kütüphanesi, okuma listeleri, ayrı alıntılar. `/user/profile`, `/user/works`, `/public/profile/:id`, `/logs/:id`, `/quotes/my`, `/quotes/user/:id`. |
| Profil görselleri | Mevcut `POST /user/banner`, `DELETE /user/banner`, avatar eşdeğerleri. Yüklemeden sonra profil yeniden okunur; hata ve yükleme durumu görünür. Görsel düzenleme seçenekleri açılır. |
| `Feed.jsx` | Kompakt paylaşım başlatıcı, ayrı `/compose` ekranı, görünürlük ve bağlı eser seçimi; `/logs`, `/feed`. Misafirde mevcut herkese açık `/feed/top-logs`. |
| `ExplorePage.jsx` | Arama, tür/sıralama, eser/yazar seçimi; mevcut `/works/discover`, `/works/genres`, `/search/users`. Geniş pencerede iki sütun. |
| `StudioPage.jsx`, `WorkStudioPage.jsx` | Atölye: eser oluşturma, cihaz taslakları, bölüm listesi, kapak/bilgi düzenleme, notlar/karakterler/olay örgüsü/evren. Tablette eser listesi ve seçilen eserin çalışma alanı yan yana. |
| `Library.jsx`, `StoryDetailsPage.jsx`, okuma ekranı | Kütüphane, okuma listeleri, bölüm geçişleri, ilerleme, alıntı ve yorum ekranları. `/library`, `/reading-lists`, `/reading-progress`, `/public/works`, `/quotes`. |
| `TopBar.jsx`, `Ayarlar.jsx` | Beş ana sekme: Akış, Keşfet, Atölye, Kütüphane, Profil. Bildirim üstte, ayarlar profilde. Açık/koyu/sistem tercihi cihazda kalıcıdır. |

Webdeki Playfair Display, Lora ve DM Sans ailesi yerel dosyalarla kullanılır. Kırık beyaz kâğıt, mürekkep ve yeşil/teal vurgular ortak `useUI` tema bağlamından gelir. Her ekranın tema bağımlılığı bağlama taşındı; editörün teması belgesini yeniden yüklemeden güncellenir.

## Davranış kararları

- Mobil koç rotası, menüler ve servis çağrıları kaldırıldı. Bağımsız yazma araçları ve web/backend koç özellikleri korunur.
- Tam bölüm metninin mevcut sunucu sözleşmesi üyelik ister. Mobil misafire bu sınırı aşan içerik vermez; keşif, eser bilgileri ve herkese açık profil alanları açıktır.
- Profilde başka kişinin özel kütüphanesi/taslak sekmesi gösterilmez. Sunucunun yayın ve sahiplik filtreleri ayrıca entegrasyon testinde doğrulanır.
- Yazma kaydında cihaz ve sunucu durumları ayrıdır. Cihaz kaydı başarısızsa korunmuş gibi gösterilmez; çıkış engeli sürer. Sürüm çakışması mekanizması korunur.
- Günlük taslağı hesaba göre cihazda saklanır. Paylaşım başarılı olmadan silinmez.
- Pencere genişliği ve sistem yazı ölçeği geniş düzen kararını belirler. Yön kilidi kaldırıldı; tablet gezinmesi yan menüye geçer. Profil ve Atölye iki alanlıdır.

## Doğrulamanın sınırları

Başarılı kontroller: TypeScript, lint, 55 mobil test; gerçek izole Express/MongoDB ile dört mobil akış testi; 45 açık/15 koyu tema tarayıcı düzeni; tema kalıcılığı ve sistem geçişi; günlük taslağının yeniden açılması. Android 1.0.2/3 release APK ve iOS Hermes paketi üretildi. Komutlar:

```powershell
npm.cmd run typecheck
npm.cmd run lint
$env:MOBILE_EDITOR_BROWSER='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm.cmd test
# Ayrı terminalde:
node scripts/design-preview.mjs
# Ardından:
node scripts/check-design-browser.cjs
node scripts/check-redesign-themes.cjs
npm.cmd run android:preview
npx.cmd expo export --platform ios
```

Görsel tarayıcı denemeleri gerçek mobil bileşenleri RN Web üzerinden, kontrollü verilerle render eder. Bunlar gerçek telefon klavyesi, native sekme çubuğu, kamera/galeri veya TalkBack/VoiceOver kabul testi yerine geçmez.

Android/iOS cihazı bu oturuma bağlı değildir; Windows üzerinde iOS native derlemesi yapılamaz. Gerçek Cloudinary hesabına görsel gönderip fiziksel telefonda yeniden açma testi bu oturumda yapılmadı. Banner işlemleri var olan gerçek API’ye bağlıdır; bu test ayrıca yapılmalıdır.

Google, EAS, APNs/FCM hesap ve sertifika gereksinimleri README’deki mevcut kurulum şartlarına tabidir. Yerel APK mevcut `.env` API adresine bağlanır; telefonun backend’e erişebilmesi gerekir.
